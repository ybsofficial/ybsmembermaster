FAQ HostMember

Pertanyaan yang Sering Ditanyakan

Jawaban singkat tentang HostMember Personal, HostMember Master, instalasi cPanel, fitur lisensi, update otomatis, dan kebutuhan hosting.

Apa itu HostMember?

HostMember adalah sistem jualan berbasis PHP, cPanel, dan MySQL untuk menjual produk digital, produk fisik, membership, LMS, lisensi software, blog, dan affiliate dari hosting sendiri.

Apa bedanya paket Personal dan Master?

Paket Personal cocok untuk pemilik bisnis yang memakai HostMember di website sendiri. Paket Master cocok untuk penjual/reseller yang ingin membuat lisensi client, mengelola update, dan menjual paket personal.

Apakah HostMember bisa berjalan di shared hosting cPanel?

Bisa. HostMember dibuat untuk hosting cPanel standar dengan PHP, MySQL atau MariaDB, cURL, ZipArchive, dan cron job. File media disimpan langsung di hosting.

Apakah bisa menjual produk fisik?

Bisa. Produk fisik mendukung input alamat checkout, berat produk, cek ongkir otomatis, pilihan kurir, biaya pengiriman, dan status pengiriman.

Apakah bisa membuat lisensi produk otomatis?

Bisa. HostMember mendukung lisensi auto generate, input manual sampai 25 digit, dan import stok lisensi dari Excel, CSV, atau TXT. Lisensi yang sudah dipakai akan ditandai otomatis.

Bagaimana cara update versi HostMember?

Paket Personal bisa memakai update otomatis dari admin. Paket Master menyiapkan paket update untuk client sehingga pengguna tidak perlu upload ulang file manual ke cPanel setiap ada versi baru.

Apakah mendukung WhatsApp Business resmi Meta?

Bisa. HostMember mendukung WhatsApp Business Cloud API Meta berbasis template, serta gateway WhatsApp lain yang memakai copywriting bawaan HostMember.

Apakah HostMember cocok untuk SEO?

Cocok. HostMember memiliki blog/artikel, halaman CMS, visual builder, landing page produk, FAQ, dan konten edukasi yang bisa dipakai untuk membangun traffic organik.
